2. 起動のしかた

  1. ダウンロードした ZIP を右クリック →「すべて展開」で展開する（中身のまま実行すると動きません）。
  2. 出てきたフォルダの中の 起動.bat をダブルクリック。
  3. 黒い画面が出て、ブラウザが自動で開きます（開かなければ http://127.0.0.1:8791/ を貼り付け）。
  4. 終わるときは、その黒い画面（ウィンドウ）を閉じます。
初回に「WindowsによってPCが保護されました」と出たら →「詳細情報」→「実行」で起動できます（自作アプリのための確認です）。
  1. ダウンロードした ZIP をダブルクリックして展開する。
  2. フォルダ内の 起動.command を、初回だけ 右クリック →「開く」→ もう一度「開く」（2回目以降はダブルクリックでOK）。
  3. 黒い画面が出て、ブラウザが自動で開きます（開かなければ http://127.0.0.1:8791/ を貼り付け）。
  4. 終わるときは、その黒い画面（ターミナル）を閉じます。
「Python3 が見つかりません」と出たら、画面の案内（Apple公式ツールの「インストール」）に従い、数分待って完了後にもう一度 起動.command を実行してください（1回だけの作業です）。

3. かんたんな使い方

  1. 上のタブでページを切り替えて書く（表題／要約／問題と目的／方法／結果／考察）。各欄の「言い回しチップ」を押すと下書きが入るので、〇〇・△△を自分の研究の言葉に置きかえる。
  2. 文献をさがす：右側で CiNii（和文） OpenAlex（国際） CrossRef（欧文） を選んで検索 →「＋文献に追加」。
  3. 投稿規定を選ぶ：日本心理学会／日本心理臨床学会／日本人間性心理学会。選んだ書式で引用文献リストが自動整形されます。
  4. 本文に引用を挿入：各セクションの「＋本文に引用を挿入」で （著者, 年） をその場に差し込み。
  5. 図表を入れる：右の「図表を取り込む」で Excel/CSV（表）や画像（図）を追加。本文に「表1」「図1」と書くと、Word出力でその位置に入ります。
  6. 書き出す：「📄 Wordで保存（図表入り）」で完成原稿（.docx）をダウンロード。コピーやテキスト保存も可能。
入力はブラウザに自動保存されます。引用文献は選んだ学会の規定で自動整形しますが、データ元により著者表記・巻号・ページが欠けることがあります。提出前に必ず原典と投稿規定で確認してください。

4. 更新について

新しい版が出ると、アプリ起動時に画面上部で「🔔 新しい版があります」とお知らせします。その際は、このページから最新版を入手して入れ替えてください。現在のバージョンはアプリ画面の一番下に表示されます。
